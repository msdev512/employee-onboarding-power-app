# Security and Governance

- Apply least-privilege access to employee and task data.
- Separate general onboarding progress from sensitive HR information when required.
- Enforce permissions at the data source, not only in the Power Apps interface.
- Use approved accounts for application and flow ownership.
- Keep credentials, secrets and tenant identifiers out of repository files.
- Apply appropriate Data Loss Prevention policies.
- Define retention rules for onboarding records, documents and audit history.
- Separate development, testing and production where governance requires it.

## Privacy

Collect only the employee data required for onboarding. Restrict sensitive fields to authorized HR or administrative roles and avoid exposing personal information in broad email or Teams notifications.
