# Project Assets

Add sanitized project visuals using these recommended filenames:

- `project-thumbnail.png`
- `onboarding-dashboard.png`
- `employee-record.png`
- `department-tasks.png`
- `progress-tracking.png`
- `notification-sample.png`

Before publishing, remove employee names, photographs, emails, client branding, tenant URLs, environment identifiers and confidential HR information.
