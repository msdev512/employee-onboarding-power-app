# Sample Department Task Template

| Department | Example task | Required |
|---|---|---|
| Direct Manager | Confirm role-specific first-week plan | Yes |
| IT | Prepare approved hardware | Yes |
| User Administration | Create required user accounts | Yes |
| Network | Configure approved network access | As required |
| Application Access | Assign approved systems and licenses | As required |
| Security | Complete security-access review | Yes |
| Operations | Confirm operational readiness | Yes |
| HR | Complete onboarding review | Yes |

These examples are generic. Production task templates must be approved by the relevant business owners.
